# Topo documentation

Map a repository on your computer, explore the evidence in your browser, and
query the same graph through your agent. No account, source upload or model key.

## Start with one useful answer

**New to Topo?** [Make your first map](/docs/quickstart/). Install once, collect a
Git repository, then find a file's known consumers or dependencies.

**Just looking?** [Explore the fictional example](/demo/). It illustrates the
workspace, not a scan of your repositories or a connected cloud account.

**Received a map?** Open its `index.html` and [learn the controls](/docs/using-the-map/).
You do not need to install Topo to view an offline bundle.

## Look up exact details

Use [CLI reference](/docs/cli/) for commands and flags, [graph reference](/docs/graph/)
for JSON fields and IDs, and [collection limits](/docs/limitations/) for supported
languages and unresolved cases. [Privacy](/docs/privacy/) owns what is read,
exported and shared.

Topo {{version}} is a read-only source-mapping preview. Static declarations are
not live runtime connections, health checks or complete infrastructure discovery.
Unknown stays unknown. Deeper sections in the guides expand when you need them;
you do not need to learn the graph format before making your first map.
