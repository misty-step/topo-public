# What this preview knows

Topo {{version}} is useful source mapping, not a maintained cloud inventory service.
Unknown is not healthy, absent, free or retired.

## Supported collection

- Rust `use`/`mod` declarations with `syn`.
- Go and JS/TS static import/re-export/literal require/import requests through
  embedded Tree-sitter grammars, called from Rust. Target programs are not run.
- Cargo/npm/Go package declarations.
- Directory-module, repository and caller-selected portfolio projections.
- Infrastructure imports accept the documented native snapshot schema, not arbitrary inventories.

Native syntax trees separate comments and string lookalikes from imports.
Syntax recovery may preserve some known declarations while reporting diagnostics.
Neither grammar parsing nor an import statement proves active execution.

## Known gaps

Dynamic targets, JS path aliases, Go workspaces/nested-manifest contexts, Cargo
workspace/target tables, activated features, semantic symbols, runtime calls,
deployment/config bindings, Python/shell and provider APIs need additional
collection/resolution. Bare imports without an established target remain
unresolved, not manufactured vendors.

Repository IDs use explicit caller namespaces; native hosting/provider identity
and rename lineage are not established. Scope is a projection, not authorization
or complete organization discovery. Shared package names do not prove equal
installed versions, deployed identity, duplicated costs or failure impact.

There is no hosted data store, automatic refresh, accepted-revision workflow,
model inference, generative runtime, provisioning or remediation service.
Maps work without those. Native iPhone Safari and organization-scale performance
are not established by the desktop/compact browser checks.

## Collection budgets and failure

Each repository input permits up to 2,000 supported files, 1 MiB/file and 16 MiB
source bytes. Ignored/generated/credential paths and symlinks are excluded. Failed,
denied, malformed or skipped paths remain unknown. A zero count is only a count
of the supplied supported evidence, never proof that a resource does not exist.

A live worktree is not an atomic checkout: file hashes identify observed bytes;
Git HEAD/dirty status is context. Dated imports retain their original dates and
gaps, not a fresh provider or health observation.

## Troubleshooting

| Result | What to do |
| --- | --- |
| Git not found | Install Git and retry; no Rust/Go/Bun toolchain is needed |
| Not a repository root | Use the Git root, not a subdirectory; select module scope after collection |
| HEAD missing | Use a repository with at least one commit |
| Output already exists | Choose a new output directory; previous maps are retained |
| Unresolved alias/import | Read its evidence; add independent resolution evidence rather than assuming absence |
| Syntax/read/budget error | Inspect collection errors, fix access/support/size and recollect into a fresh directory |
| Sparse map for another language | The collector does not yet support that source language; it does not prove no dependencies |
